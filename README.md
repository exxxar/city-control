# Город под контролем

Веб-платформа для взаимодействия жителей и городской администрации: граждане сообщают о проблемах, поддерживают городские инициативы и подают заявки на мероприятия, а администрация модерирует обращения, назначает исполнителей и контролирует выполнение работ.

## ✨ Ключевые возможности

### 👥 Для граждан (Client)

- Регистрация и аутентификация.
- Создание обращений о городских проблемах с указанием категории, описания и геолокации.
- Голосование за городские инициативы.
- Просмотр статусов собственных обращений и инициатив.
- Подача заявок на проведение городских мероприятий.

### 👑 Для администрации (Admin Panel)

- **Дашборд:** сводная статистика, интерактивные графики на Chart.js и последние события.
- **Управление пользователями:** поиск, фильтрация, блокировка и назначение ролей.
- **Ролевая модель (RBAC):** создание пользовательских ролей и настройка детализированных разрешений.
- **Модерация:** одобрение и отклонение обращений и инициатив, назначение ответственных исполнителей.
- **Контроль отчётов:** проверка отчётов исполнителей с фотографиями «до/после», перечнем материалов и стоимостью; принятие отчёта или возврат на доработку.
- **Справочники:** управление категориями проблем, решений и трудностей.
- **Экспорт данных:** выгрузка таблиц пользователей, проблем и отчётов в формат `.xlsx`.
- **Журнал аудита:** фиксация действий администраторов.

## 🧰 Технологический стек

- **Frontend:** Vue 3, Vite.
- **Backend:** Python, FastAPI.
- **База данных:** MySQL 8.
- **Миграции:** Alembic.
- **Управление Python-зависимостями:** Poetry.
- **Аналитика:** Chart.js, vue-chartjs.
- **Экспорт в Excel:** `xlsx`, `file-saver`.

## 🚀 Быстрый старт (локальная разработка)

### 1. Предварительные требования

Перед началом убедитесь, что установлены:

- Python 3.11 или новее;
- Node.js 18 или новее;
- MySQL 8.0 или новее;
- Poetry.

### 2. Создание базы данных

Создайте базу данных MySQL:

```sql
CREATE DATABASE city_under_control
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

### 3. Настройка Backend

Перейдите в каталог backend:

```bash
cd backend
```

Установите зависимости:

```bash
poetry install
```

Создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и укажите параметры подключения к MySQL и остальные необходимые переменные окружения.

Примените миграции базы данных:

```bash
poetry run alembic upgrade head
```

При необходимости заполните базу тестовыми данными:

```bash
poetry run python seed_test_data.py
poetry run python seed_initiatives.py
poetry run python seed_reports.py
poetry run python seed_events.py
```

### 4. Настройка клиентской части

В отдельном терминале из корневого каталога проекта выполните:

```bash
cd client
npm install
npm run dev
```

### 5. Настройка административной панели

Откройте ещё один терминал из корневого каталога проекта:

```bash
cd admin
npm install
npm run dev
```

### 6. Запуск всех компонентов в Windows

В корневом каталоге проекта запустите:

```bat
start-all.bat
```

Скрипт открывает три окна терминала и запускает Backend, Client и Admin.

| Компонент | Адрес по умолчанию |
|---|---|
| Backend (FastAPI) | `http://localhost:8000` |
| Client (Vite) | `http://localhost:5173` |
| Admin (Vite) | `http://localhost:5174` |

> Если адреса или порты переопределены в конфигурации проекта, используйте значения из соответствующих файлов настроек и вывода терминала.

## 🔑 Тестовые учётные записи

После выполнения скриптов заполнения (`seed_*.py`) могут быть доступны следующие тестовые аккаунты:

| Роль | Email | Пароль | Доступ |
|---|---|---|---|
| Системный администратор | `admin@city.local` | `admin123` | Полный доступ к административной панели |
| Модератор | `mod@city.local` | `mod123` | Модерация обращений, инициатив и отчётов |
| Исполнитель | `exec1@city.local` | `exec123` | Просмотр назначенных задач |
| Пользователь | `user1@city.local` | `user123` | Доступ к клиентской части |

> **Важно:** это демонстрационные учётные данные для локальной разработки. Не используйте их в рабочем окружении. Перед развёртыванием измените пароли и проверьте настройки безопасности.

## 📦 Экспорт и аналитика

### Экспорт в Excel

Экспорт табличных данных реализован через composable `useExport` с использованием библиотек `xlsx` и `file-saver`. Предусмотрена выгрузка данных в формате `.xlsx` с русскоязычными заголовками.

### Аналитика

Для визуализации статистики на административном дашборде используются `chart.js` и `vue-chartjs`.
